# 📜 One-Time Scripts Catalog

Каталог полезных одноразовых скриптов для браузера. Без сервера, без зависимостей, максимально просто.

**🌐 Живой каталог: [https://genaforvena.github.io/one-time-scripts-catalog/](https://genaforvena.github.io/one-time-scripts-catalog/)**

## 🚀 Как пользоваться
1. Найдите нужный скрипт в каталоге.
2. Нажмите кнопку **"Копировать код"**.
3. Откройте нужный сайт, нажмите `F12` (Консоль), вставьте код и нажмите `Enter`.

## 📦 Категории скриптов
- **Anti-Annoyance:** Пропуск рекламы, удаление баннеров куки.
- **Social:** Автоматизация в Instagram и LinkedIn.
- **Security:** Раскрытие скрытых паролей.
- **Productivity:** Оценка времени чтения, блокировка отвлекающих факторов.
- **Scraping:** Экспорт email-адресов и данных.
- **Dev Tools:** Очистка уведомлений GitHub.

## 🛠 Технологии
- HTML5 / CSS3 (Vanilla)
- JavaScript (Vanilla)
- JSON для хранения данных
- GitHub Pages для хостинга
