## Как добавить свой скрипт

1. Форкните этот репозиторий.
2. Отредактируйте файл `scripts.json`.
3. Добавьте свой объект в массив `scripts` (следуйте существующей структуре).
4. Создайте Pull Request.

### Структура JSON:
```json
{
  "id": "unique-id",
  "name": "Название скрипта",
  "description": "Краткое описание того, что он делает.",
  "code": "Весь JS код скрипта одной строкой (или с \\n)",
  "category": "video/fun/shopping/etc",
  "author": "ваш-никнейм",
  "url": "ссылка-на-ваш-профиль-или-репо (опционально)",
  "instructions": "Пошаговая инструкция для пользователя",
  "tags": ["тег1", "тег2"]
}
```

Если вы не умеете пользоваться Git, просто создайте Issue с кодом и описанием вашего скрипта!
