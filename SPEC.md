# 📄 ТЗ: One-Time Scripts Catalog v1.0

## 1. 🎯 Цель
Создать **простейший каталог одноразовых скриптов** для браузера, который работает на GitHub Pages, не требует сервера и позволяет:
- Добавлять скрипты через Pull Request (или вручную редактируя JSON)
- Копировать код одной кнопкой
- Делиться ссылкой на конкретный скрипт
- Иметь приличный вид на телефоне и компьютере

---

## 2. 🧱 Архитектура (максимально просто)

```
/ (корень репозитория)
├── index.html          # Главная / список скриптов
├── script.html         # Страница отдельного скрипта (опционально)
├── scripts.json        # Все данные о скриптах в одном файле
├── style.css           # Один общий стиль
├── script.js           # JS для фильтрации/рендера
└── README.md           # Инструкция для контрибьюторов
```

**Хостинг:** GitHub Pages (ветка `gh-pages` или просто корень `main`)

## 4. 🖥 Функциональность

### Главная страница (index.html)
- [x] Заголовок + краткое описание проекта
- [x] **Поле поиска** (фильтр по названию/описанию/тегам)

- [x] Полное название и описание
- [x] **Большая кнопка копирования кода**
- [x] Пошаговая инструкция (из JSON)

## 5. 🎨 Дизайн (минимализм)

- **Цвета:** Белый фон, черный текст, один акцентный цвет (например, `#4CAF50` для кнопок)
- **Шрифт:** Системный (без загрузки шрифтов)
- **Анимации:** Только hover-эффекты на кнопках
- **Иконки:** Можно использовать [Font Awesome](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0-beta3/css/all.min.css) (бесплатно)
- **QR-коды:** Генерировать через API (например, `https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=URL`)

## 6. 🔧 Технические детали

### Кнопка копирования
```javascript
function copyCode(code) {
  navigator.clipboard.writeText(code).then(() => {
    alert('Код скопирован!');
  });
}
```

### Поиск и фильтры
- Фильтрация происходит **на клиенте** (без перезагрузки)
- При поиске обновляется URL с query-параметром (чтобы можно было дать ссылку на результаты)

### Роутинг (для script.html)
```javascript
// Получаем id из URL
const urlParams = new URLSearchParams(window.location.search);
const scriptId = urlParams.get('id');
// Ищем скрипт в scripts.json и рендерим страницу
```

### GitHub Pages
- Включить в настройках репозитория
- Домен: `username.github.io/repo-name`

## 7. 📝 Контрибьюция (как добавить скрипт)

Создаём файл `CONTRIBUTING.md`:

```
## Как добавить свой скрипт

1. Форкни репозиторий
2. Отредактируй файл `scripts.json`
3. Добавь свой объект в массив `scripts`
4. Сделай Pull Request

Или напиши мне в Issues, если не умеешь в git.
```

---

## 8. 🚀 Запуск "в одну кнопку"

1. Создать репозиторий на GitHub
2. Залить index.html + scripts.json + style.css
3. Включить GitHub Pages в Settings
4. Готово! Ссылка: `https://username.github.io/repo-name`

## 10. 🤔 Почему это сработает

- **Минимум зависимостей** — не ломается со временем

- **Шеринг** — ссылкой на конкретный скрипт можно поделиться в чате
