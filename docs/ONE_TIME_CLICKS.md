# One-Time Click Scripts

Эта коллекция содержит скрипты для массового выполнения кликов на популярных веб-ресурсах. Эти скрипты полезны для автоматизации рутинных задач, требующих множества одинаковых действий.

## 📦 Список скриптов

### 1. 💖 Instagram: Лайкнуть всё
- **Файл:** `src/scripts/one-time-clicks/ig-like-all.js`
- **Описание:** Проходится по всем видимым постам в ленте или профиле и нажимает кнопку "Лайк".
- **Инструкция:** Откройте Instagram, прокрутите до нужного места, откройте консоль (`F12`), вставьте код и нажмите `Enter`.

### 2. 🤝 LinkedIn: Массовое подключение
- **Файл:** `src/scripts/one-time-clicks/li-connect-all.js`
- **Описание:** Автоматически нажимает кнопку "Connect" для всех предложенных контактов в разделе "People you may know".
- **Инструкция:** Зайдите в раздел [My Network](https://www.linkedin.com/mynetwork/), вставьте код в консоль.

### 3. 🗑️ GitHub: Очистка уведомлений
- **Файл:** `src/scripts/one-time-clicks/gh-clear-notifications.js`
- **Описание:** Выбирает все уведомления на текущей странице и нажимает кнопку "Done" (Архивировать).
- **Инструкция:** Откройте [GitHub Notifications](https://github.com/notifications), вставьте код в консоль.

## 🛠 Разработка и расширение
Чтобы добавить новый "клик-скрипт":
1. Создайте новый `.js` файл в директории `src/scripts/one-time-clicks/`.
2. Используйте `setTimeout` для задержки между кликами, чтобы избежать блокировок со стороны сайтов.
3. Опишите новый скрипт в `scripts.json` для отображения в каталоге.
